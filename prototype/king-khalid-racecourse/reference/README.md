# مجلد المرجع — REFERENCE ALIGNMENT MODE

- `reference_landmarks.json` — نقاط الـ Landmarks المرقمنة بصرياً من الصورة الجوية
  المرجعية (إحداثيات النموذج بالمتر + إحداثيات الصورة المنسّبة + تحويل الربط بينهما).
- **الصورة الجوية الأصلية**: ضع نسخة منها هنا باسم
  `kkrc_aerial_reference.jpg` (أو `.png`) وسيحمّلها وضع المحاذاة تلقائياً كطبقة
  Overlay فوق المشهد. بدونها يعرض الوضع مخططاً مرسوماً من نقاط الـ landmarks
  المرقمنة، ويمكن أيضاً سحب الصورة وإفلاتها على الصفحة مباشرة.
- إعدادات المحاذاة (شفافية/تحجيم/تدوير/إزاحة) قابلة للتصدير من داخل الوضع إلى
  `reference_alignment.json` بزر export JSON.

تشغيل الوضع: زر `REF` في الواجهة أو مفتاح `R` — يتحول تلقائياً إلى كاميرا
TopOrthographic مع شبكة 50م اختيارية وعلامات الـ landmarks.
