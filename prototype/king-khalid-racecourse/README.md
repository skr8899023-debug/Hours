# King Khalid Racecourse — Scene Prototype

نموذج مستقل عالي الجودة لمشهد ميدان الملك خالد، مبني بـ Three.js (منسوخة محلياً في
`vendor/` — لا حاجة لاتصال إنترنت ولا خطوة build). **لا يحتوي أي منطق لعبة أو
Mobile Controller** — الهدف هو الـ fidelity البصري والهندسي فقط.

## التشغيل

```bash
cd prototype/king-khalid-racecourse
python3 -m http.server 8000     # أو: npm start
# ثم افتح http://localhost:8000
```

التبديل بين الكاميرات: الأزرار أعلى الشاشة أو المفاتيح `1`–`4`
(Aerial / Trackside / Grandstand / Overview). السحب بالفأرة يدير الكاميرا النشطة.

## البنية (فصل الطبقات)

| المسار | الدور |
|---|---|
| `src/track_definition.js` | **مصدر الحقيقة الوحيد**: أبعاد المضمار، دوال centerline/offset، مراسي الكاميرات — رياضيات صرفة بلا اعتماد على أي محرك رسم |
| `src/geometry.js` | بُناة الأسطح: أحزمة المضمار، السياجات، المنطقة الداخلية، الممرات، خط النهاية |
| `src/materials.js` | مكتبة الخامات (ألوان + إزاحة ضوضاء إجرائية مولّدة بلا ملفات خارجية) |
| `src/props.js` | المجسمات: النخيل (instanced)، المدرج والمباني، معالم المنطقة الداخلية، أعمدة الإنارة، البيئة البعيدة |
| `src/environment.js` | الإضاءة النهارية: قبة سماء، شمس بظلال، ضباب مسافة |
| `src/cameras.js` | كاميرات العرض الأربع + OrbitControls |
| `src/main.js` | نقطة الدخول: تجميع فقط، بلا منطق لعبة |
| `metadata/kkrc_track_metadata.json` | **الملف القابل للنقل**: centerline، حدود الحارات، مراسي العوائق، بوابات البداية، خط النهاية، مراسي الكاميرات |
| `tools/export_metadata.mjs` | مولّد الـ metadata (`npm run export-metadata`) — يقرأ من `track_definition.js` نفسه فلا يمكن أن يختلف عن المشهد |

## نظام الإحداثيات

يمين-اليد، Y للأعلى، الأرض على مستوى XZ، الوحدة متر، نقطة الأصل مركز الحلبة.
`s` = المسافة القوسية على الـ centerline (تبدأ غرب المستقيم الرئيسي الجنوبي، عكس
عقارب الساعة). الإزاحة الجانبية `o` موجبة نحو الداخل.

## الأداء

مقاس فعلياً (WebGL, 1600×900): **≤ 100 draw calls، ~43k مثلث، 6 خامات نسيجية** —
كل العناصر المتكررة (نخيل، أعمدة، شجيرات، تلال، مبانٍ بعيدة) عبر `InstancedMesh`.
